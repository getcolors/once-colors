PRODUCTION DESIRED STATE

once-colors

The live desired state for www.getcolors.ai: ONCE on Oracle Cloud with Cloudflare DNS, Resend mail, and R2 state.

  • ONCE
  • Oracle Cloud
  • Production
  • Three colours

#Overview

This repository contains deployment configuration, not application source. colors.yml declares one OCI server and the Colors website container. Green, Red, and Blue are interchangeable managers of the same state.

#Architecture

www.getcolors.ai → Cloudflare → OCI VM → ONCE → colors-website container
                         ↘ Resend SMTP
operator → Green/Red/Blue → OpenTofu state in R2

#Desired state

Edit colors.yml only. It selects OCI compute, Cloudflare DNS, Resend SMTP, R2 state, and the application image. Application source lives in colors-website.

#Safe inspection

./green describe
./green build
./green create --dry-run

#Operations and safety

Production systemReal lifecycle commands affect the live Colors website. Keep the destroy guard enabled, never export COLORS_PAR_PROFILE, and never edit generated .colors/.

#Package relationship

The three root launchers are copies of installed package-once-* payloads. After npx skills update -p, re-copy all three so their pins and skills-lock.json remain aligned.
